Dockerfile Test 2: ARG and ENV Test

Exercise Description

This exercise is designed to practice Dockerfile basics and understand the difference between ARG and ENV.

The Docker image uses a Python base image and starts a simple HTTP server inside the container to serve this static HTML page.

Exercise Task

Create a Dockerfile that uses ARG as a build-time variable and ENV as an environment variable stored in the image/container.

During the image build process, use these values to create an app-info.txt file.

Main Learning Goal

ARG is mainly used during docker build. It can be changed with --build-arg when building the image.

ENV is stored in the image and can still be available when the container is running.

Expected Test Result

After building and running the image, open the generated file below to check the build-time information:

Open app-info.txt

Commands Used

Build with default ARG value:

docker build -t dockerfile-level2 .

Build with a custom ARG value:

docker build -t dockerfile-level2:v2 --build-arg BUILD_VERSION=2.0 .

Run the container:

docker run --rm -p 8000:8000 dockerfile-level2
